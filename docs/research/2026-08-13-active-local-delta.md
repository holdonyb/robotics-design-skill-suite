# Active Local Robotics Skill Delta

## Scope

This is a read-only classification of the active installed `robotics-design`
tree against the public `v0.2.0` source. The system installation and the
default user installation were byte-identical at review time. Neither installed
copy was changed during this audit.

The dispositions are:

- `promote_with_tests`: useful behavior may enter Git only with focused tests;
- `superseded_by_v020_review_fix`: the public reviewed implementation is newer
  or stricter and remains authoritative;
- `host_only`: machine/runtime state must not enter portable source;
- `generated_drop`: generated artifacts are excluded from source and installs.

## Promotion rule

The installed tree is not a merge base and is never copied wholesale. A
`promote_with_tests` item must be re-authored against the public contract, pass
RED/GREEN behavior tests, contain no host paths or generated bytecode, and pass
independent review. All other dispositions require no source import.
