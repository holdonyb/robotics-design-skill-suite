# v0.7 Completion Audit

This audit covers the v0.7 bench-evidence intake release candidate. It can
validate future raw component measurements; it cannot create, edit, acquire,
or replay those measurements as if they were physical results.

| Exit gate | Evidence | Status |
|---|---|---|
| Raw measurement binding | Local regular CSV path, SHA-256, exact headers/units, finite values, monotonic timestamps, and declared summary checks | MET |
| Calibration provenance | Hash-bound local certificate, matching instrument identity, and observation-date validity window | MET |
| Test-card/provenance boundary | Approved-for-recording card, authority, E-stop/energy/abort fields, site/operator and component/claim edges required | MET |
| Fixture boundary | Complete parser fixture is marked `fixture_only` and cannot claim a reference measurement | MET |
| Reference intake | Empty reference index returns `awaiting_authorization`, not `bench-tested` | MET |
| Hardware authority | Reports derive `procurement_authorized: false` and `motion_authorized: false` | MET |
| Candidate CI and publication | Pending after this audit commit | PENDING RELEASE |

## Claim boundary

No v0.7 action authorizes purchasing, fabrication, energizing, movement, or
device access. Real bench evidence still requires externally authorized
equipment, a controlled site, qualified operators, a reachable E-stop, bounded
energy, an approved test card, instrument calibration and original retained
data. `fixture_only` proves parser behavior only.
