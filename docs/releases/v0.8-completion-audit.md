## Claim boundary

No v0.8 action authorizes purchasing, fabrication, assembly, energizing,
device access, or motion. A complete local record is only an internally
consistent submission. A real hardware result requires external site and motion
authority, a bounded area, reachable E-stop, qualified roles, controlled
limits, independently retained records, and an attestation mechanism outside
this repository.
