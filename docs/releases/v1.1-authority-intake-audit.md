# v1.1.0 Authority Intake Candidate Audit

This candidate adds a hash-bound, externally supplied human-attestation record
to retained commissioning evidence. It is a software and evidence-boundary
release, not a hardware-validation claim and not a hardware authorization.

## Delivered boundary

- A recorded commissioning phase now binds a canonical regular local authority
  record by path and SHA-256.
- The record closes its schema and must cover the exact design-contract digest,
  phase, inclusive execution-date window, site, area, reachable emergency
  stop, observer roles, energy/speed/torque maxima, and watchdog timeout.
- Wrong hash, symlink/path, malformed JSON, expired date window, scope drift,
  or a phase limit/timeout above the attested maximum produces deterministic
  `COMM.AUTHORITY_*` findings and blocks readiness.
- Planned phases cannot attach an authority record. A complete retained package
  still derives `procurement_authorized: false` and
  `motion_authorized: false`; no local record controls equipment or authorizes
  purchasing, energization, or motion.

## Release integrity

The published `v1.0.0` contract is left unchanged and remains independently
verifiable against its tag. v1.1.0 adds a distinct canonical contract that
binds the authority route, commissioning validator and runtime, release
validator runtime, public documentation, and existing public boundary files.
The normal distribution check selects only `release/v1.1-release-contract.json`
for manifest version `1.1.0`.

## Candidate verification

Before publication, require all of the following at the reviewed head:

```text
python -m unittest discover -s tests -v
python scripts/validate.py
python scripts/install.py --dry-run
python -m compileall -q scripts tests skills/robotics-design/scripts
git diff --check
```

Then require reviewed-head CI and Jazzy/Harmonic consumer-gate success, the
merged-main equivalents, and a passing annotated `v1.1.0` tag before creating
a non-draft GitHub Release. None of those software checks is real-hardware
evidence or permission to operate a robot.
