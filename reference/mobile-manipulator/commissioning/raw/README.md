# Commissioning raw-record boundary

This directory intentionally contains no commissioning evidence. Do not place
generated, simulated, copied, hand-edited, or fabricated command, state, stop,
inspection, or motion records here.

Future real records require external site and motion authority, a bounded area,
a reachable emergency stop, named roles, controlled energy limits, and retained
original data. The local validator cannot provide those conditions or control
any device.
